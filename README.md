NoteStack 📝
============

NoteStack is a full-stack productivity app for students to manage their notes and tasks in one place. It is built with the MERN stack and deployed on Render.

Features
--------

**Notes:** Create, view, edit, and delete notes, and mark important ones with a star ⭐.

**Bookmarks:** Bookmark notes 🔖 and find all your saved notes together in one place.

**Tasks:** Add tasks with due dates, tick them off when done, and edit or delete them anytime.

**Dashboard:** See important notes, tasks due today, and upcoming tasks at a glance.

How It Works
------------

The frontend is a React app built with Vite, styled with Tailwind CSS and daisyUI, and uses React Router and Axios. The backend is a Node.js and Express REST API with input validation and error handling, storing data in MongoDB with Mongoose. API requests are rate limited using Upstash.

Tech Stack
----------

React, Vite, Tailwind CSS, daisyUI, Node.js, Express, MongoDB, Mongoose, Upstash Redis
